# FnKeys

Fix function keys on TKL and compact keyboards under Linux by restoring them to standard F1-F12.

## TESTED DISTROS
- Fedora 38/39/40/41/42/43/44
- Debian 11/12/13
- Ubuntu 22.04/24.04/25.04/25.10/26.04
- Linux Mint 21.x/22.x
- OpenSUSE Tumbleweed
- Arch Linux
- Windows XP

## TESTED KEYBOARDS
- Newskill Serike V2 TKL

Feel free to open an issue if your keyboard also works!

## IMPORTANT
**fnKeys relies on systemd for persistence. Immutable distros (e.g., Bazzite, Fedora Kinoite) are currently untested and may not be fully supported. Distros that do not use systemd are currently fully unsupported.**

## HOW TO INSTALL
Go to the official [website](https://dankunex.com/labs/fnkeys) and follow it.
